# Kavita E-Book / Comic Reader Themes

Custom Themes für den Kavita Server auf [free-warez.win](https://free-warez.win).

---

## 📁 Struktur

- `themes/`:
  - `w-make-cyber.css`: **W-MAKE Cyber Noir** Theme mit Cyan & Smaragd Akzenten, Glassmorphism-Karten und Dark Obsidian Background.
- `deploy.sh`: Synchronisiert die CSS-Themes in das gemountete Datenverzeichnis `/opt/containers/kavita/data/themes/` und startet den Kavita-Container neu.

---

## 🚀 Deployment

```bash
./deploy.sh
```
